# 免费免登录AI问答工具 Spec

## Why
目前市面上的AI对话工具大多需要注册登录甚至付费，用户希望能有一个即开即用、无需繁琐流程且全平台支持的AI问答工具，随时随地获取解答。

## What Changes
- 创建一个全新的 React 前端项目
- 实现响应式的聊天 UI（适配移动端和桌面端）
- 集成免登录的大模型 API，支持文本对话和流式输出
- 实现对话记录的本地存储
- 支持 Markdown 和代码高亮展示

## Impact
- Affected specs: 无（新项目）
- Affected code: 项目根目录下的全新代码结构

## ADDED Requirements
### Requirement: 核心对话功能
系统应当允许用户直接输入问题并获取 AI 的回答。

#### Scenario: 发送问题并获取回答
- **WHEN** 用户在输入框中输入文本并点击发送按钮
- **THEN** 系统展示用户输入的气泡，并在下方展示带有加载状态的 AI 气泡，当 API 返回数据时逐步/完整展示回答内容（支持 Markdown）。

### Requirement: 全平台响应式支持
系统应当在各种屏幕尺寸下良好运行。

#### Scenario: 在移动设备上访问
- **WHEN** 用户使用手机浏览器打开页面
- **THEN** 界面自动适配屏幕宽度，输入框固定在底部，方便单手操作。
